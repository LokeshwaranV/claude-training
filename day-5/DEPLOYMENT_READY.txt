TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════════

Issue: API key not found
Fix: Check .env file and ANTHROPIC_API_KEY + GROQ_API_KEY variables

Issue: Port 8000/3000 already in use
Fix: lsof -i :8000 && kill -9 <PID>

Issue: Module not found error
Fix: pip install -r requirements.txt --upgrade

Issue: Frontend can't reach backend
Fix: Verify http://localhost:8000/health and check REACT_APP_API_URL

See AIDLC_DEPLOYMENT.md for more troubleshooting
