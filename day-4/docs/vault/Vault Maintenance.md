# Vault Maintenance

This vault (`docs/vault/`) is a set of plain Markdown notes using Obsidian
`[[wikilink]]` syntax — no Obsidian install or server is required to create
or read it; open the `docs/vault/` folder as a vault in the Obsidian app
(desktop/mobile) to browse it as a linked graph, or just read the `.md`
files directly.

## Update rule

After each AIDLC step that changes architecture, policy, or a major
decision, update the relevant note here (not just `docs/NEXT_SESSION_PROMPT.md`
or the per-agent state files) — those two are session/agent-scoped working
memory; this vault is the durable, cross-session "why" a new contributor
(or Obsidian graph view) would want. Prefer editing an existing note over
creating a new one unless a genuinely new topic area appears; keep
[[Home]] in sync with any new note.
